Projets

Assault Cube Multihack

Un hack interne pour le jeu (hors ligne) Assault Cube incluant de nombreuses fonctionnalités : ESP (affichage des joueurs à travers les murs), Aimbot, Triggerbot, ... Ce projet utilise des techniques de reverse engineering et d’injection de DLL pour manipuler la mémoire du jeu.

C++ Reverse Engineering Game Hacking

C++ Static Security Auditor & CI/CD Pipeline

Développement d'un outil DevSecOps complet d'automatisation de la qualité et de la sécurité du code C++. Implémentation d'un moteur d'analyse statique, de Git Hooks (scripts de pré-commit) bloquant les vulnérabilités critiques (buffer overflows, fonctions obsolètes) et automatisation complète via une pipeline Jenkins (Groovy). Piloté par un tableau de bord Web développé avec Flask.

C++ Python DevSecOps Jenkins

Pilote Système Windows — Abstraction & Modification SMBIOS

Développement d'un pilote en mode noyau (KMDF) permettant de lire, d'abstraire et de modifier dynamiquement les structures d'identifiants matériels (HWID) au niveau de la carte mère (tables SMBIOS / ACPI). Implémentation sécurisée des communications User-mode vers Kernel-mode via des requêtes IOCTL personnalisées, gestion rigoureuse de la mémoire non paginée (Non-Paged Pool) et débogage approfondi avec WinDbg pour garantir une stabilité système totale (0% BSOD).

C++ KMDF Windows Kernel WinDbg

Pilote UEFI — Émulation de Tables SMBIOS & Protection de Code

Développement en langage C d’un pilote de bas niveau au standard UEFI s'exécutant lors de la phase de pré-démarrage (Boot phase), avant l'initialisation du système d'exploitation. Conçu pour parser et modifier dynamiquement les structures de tables SMBIOS (notamment les UUID matériels) à des fins d'émulation d'environnements de test. Intégration de mécanismes de protection de code contre l'analyse statique via le chiffrement de chaînes (XOR dynamique) et conception d'une couche de gestion de mémoire pour chaînes de caractères dynamiques en C pur.

C UEFI / EDK2 Firmware Sécurité Logicielle

Framework GUI C++ — Abstraction Windows & Rendu Matériel DirectX 11

Conception et développement d'un framework d'interface graphique (GUI) léger et hautement optimisé en C++ pour les applications de bureau Windows (Win32). Implémentation d'une architecture entièrement orientée objet (POO) encapsulant la gestion des fenêtres natives, la gestion des événements système et un pipeline de rendu graphique accéléré par le matériel via DirectX 11 et ImGui. Intégration de modules réutilisables pour la gestion dynamique des polices, des palettes de couleurs et de systèmes d'animations fluides.

C++ DirectX 11 ImGui Architecture POO

Bibliothèque de Structures de Données — Réimplémentation STL compatible Kernel-Mode

Conception et développement d'une bibliothèque C++ autonome (Zero-dependency) réimplémentant les conteneurs et utilitaires fondamentaux de la STL (Vector, String, Unordered_Map, itérateurs et type_traits). Spécifiquement optimisée pour contourner l'absence de bibliothèque standard en mode noyau Windows (KMDF). Implémentation d'une gestion fine de l'allocation bare-metal via la surcharge personnalisée des opérateurs d'allocation (new/delete) interconnectés avec les pools de mémoire Kernel, utilisation avancée des templates pour la métaprogrammation et validation par tests unitaires pour assurer une stabilité système absolue.

C++ Windows Kernel Structures de Données Métaprogrammation

Éditeur de texte Console

Éditeur de texte performant développé en C++ sans bibliothèques standard pour optimiser le traitement de fichiers volumineux. Ce projet m’a permis d’améliorer ma maîtrise de la gestion mémoire, des algorithmes complexes et du développement Windows via l’API Win32.

C++ System API

Wrapper C++ pour ZIP

L’objectif principal est de rendre l’intégration ZIP en C++ plus accessible et intuitive.

C++ Librairie Minizip
